# Shreenath Ji Sarees (श्रीनाथ जी साड़ीज़) - Official Website

## ✨ Features

1. **Bilingual Experience (English & हिन्दी):**
   - Instant language switcher in the header for comfortable local browsing.
2. **Interactive Saree Catalog & Filtering:**
   - Filter by categories: Banarasi Silk, Lightweight Zari Borders, Chanderi & Maheshwari, Bridal Lounge, Organza & Tissue, Dress Materials.
   - Filter by color family (Red, Pink, Green, Blue, Yellow, Gold, Purple).
   - Instant real-time keyword search (e.g. `zari`, `banarasi`, `chanderi`).
   - Sort by Featured, Price (Low to High, High to Low), and Customer Rating.
3. **Quick View & Saree Detail Modal:**
   - Full fabric breakdown, weave type, zari description, length, blouse piece details, wash care, and occasion recommendations.
   - One-click "WhatsApp Inquire" button pre-filled with the exact saree name, code, and price.
4. **Wedding Trousseau & Draping Stylist:**
   - Interactive planner covering Haldi & Mehendi, Sangeet & Cocktail, Wedding Pheras, and Grand Reception.
   - Recommends fabrics, matching color harmonies, and draping tips.
5. **Live Video Call Shopping (WhatsApp):**
   - Built specifically for shoppers across Betul, Multai, Shahpur, Amla, Chhindwara, Parasia, and Bhopal.
   - Interactive slot booking form directly opening customized WhatsApp requests.
6. **Persistent Wishlist Drawer:**
   - Save sarees to wishlist with `localStorage` persistence.
   - Share the entire shortlist directly with the Kothi Bazar store on WhatsApp before visiting.
7. **Store Locator & Live Status:**
   - Real-time indicator calculating whether the showroom is currently open (until 9:00 PM).
   - Embedded interactive Google Map, parking instructions, and landmark guidance.
8. **Instagram Live Gallery:**
   - Direct integration displaying posts and reels linked to `@shrinath_jisarees`.
9. **Verified Customer Reviews (4.1★):**
   - Authentic reviews from Betul residents and wedding shoppers.
10. **Sticky Floating Action Bar:**
    - Instant Mobile & Desktop access to WhatsApp, Phone Call, and Google Maps Navigation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
The site runs on `http://localhost:5173/`.
